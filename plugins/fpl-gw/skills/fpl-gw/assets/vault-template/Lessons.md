# Lessons — {{SEASON}}

Rules learned from real results. Run the checklist before confirming every GW.

## Checklist before the deadline
- [ ] Is everyone in the XI sure to play? (no confirmed injury / unclear minutes for a game after the deadline)
- [ ] How many scoring routes does each XI player have (CS / DefCon / G / A / bonus)?
- [ ] Captain = the template pick? If not, is the reason more than "the fixture looks hard"?
- [ ] Do transfers pass the EV vs hit maths?
- [ ] Club count ≤ 3 and the correlation acceptable?
- [ ] Fixture ticker checked 4–6 GWs ahead for a long hold?
- [ ] Bench order: first sub = the most certain starter
- [ ] Anyone one yellow card from a ban?

## Lessons
<!-- Starter rules — keep, edit or delete them. New lessons go below as L{n+1} with a [[GWnn]] link (CLAUDE.md §5). -->

### L1
**Lineup evidence beats unfinished transfer rumours** — don't bench or avoid a player because of a rumour that hasn't happened.

### L2
**Unclear minutes + a kickoff after the deadline = keep him out of the XI.**

### L3
**Count scoring routes** — a clean-sheet-only defender is worse than one with DefCon, set pieces or attacking returns.

### L4
**Beware recency bias when picking the captain** — one big haul from someone else isn't a reason to leave the template captain.

### L5
**Finish the budget maths before saying a move works.**

### L6
**DefCon floor = 0 below 60 minutes** — rotation risk kills defensive-contribution points.

### L7
**Don't dodge the template captain just because the fixture "looks hard"** — need data, not a feeling.

### L8
**A confirmed injury never goes in the XI.**

### L9
**Use one framework through a decision** — switching criteria halfway produces flip-flopping picks.

### L10
**Check the fixture ticker before calling something a long hold.**

### L11
**Player form vs team form** — look at both.

### L12
**xGI vs G+A** — big over-performers regress; under-performers tend to bounce back.
